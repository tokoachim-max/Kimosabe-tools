Frequently Asked Questions

Everything you need to know before you start

Are my files uploaded to a server?

No — never. Every tool runs entirely inside your browser using JavaScript. Your files are processed in memory on your own device and are never transmitted anywhere. You can verify this by watching your network tab in DevTools.

Do I need to create an account?

No account, no email, no sign-up. Open a tool and start using it immediately. There is nothing to install or register.

Are there file size limits?

There are no imposed limits — we don't control file size because files never touch our servers. Processing large files may be slower depending on your device's hardware.

Do the tools work offline?

Yes. After your first visit, Kimosabe Tools installs a service worker that caches the pages. You can use all tools without an internet connection from then on.

Are there watermarks on output files?

Absolutely not. Your output files are clean, unmodified (except for the edits you made), and contain no branding or watermarks from us.

How is this free to use?

Kimosabe Tools is a passion project maintained by a solo developer. It's kept alive by voluntary donations from users who find it useful. If these tools save you time, consider buying the developer a coffee ☕.
