Frequently Asked Questions

Can I rotate only some pages, not all?

Currently the rotation tool applies to all pages in the document. To rotate only some pages, split the PDF into sections first, rotate each section, then merge them back together.

How do I extract specific pages from a PDF?

Enter the page numbers in the Split section using formats like '1-5' for a range, '2,5,7' for specific pages, or '3' for a single page.

Will rotating a PDF change the file size?

Slightly. Rotation is metadata-only in PDF, so the file size change is minimal.

Can I split a password-protected PDF?

No. Remove the password protection first, then use this tool.
